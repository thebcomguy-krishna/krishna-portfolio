# Image replacement guide

The website uses predictable filenames so you can replace placeholder assets without changing layout code. Keep the exact filename and extension when replacing an image.

| File | Used for |
|---|---|
| `public/images/profile.jpg` | Homepage portrait (your uploaded photo) |
| `public/images/sih-winner.jpg` | Smart India Hackathon winner photo |
| `public/images/toastmasters-01.jpg` | Toastmasters meeting / speaking photo |
| `public/images/toastmasters-02.jpg` | Second Toastmasters photo |
| `public/images/argus.jpg` | Reserved for Argus project image |
| `public/images/saturn-labs.jpg` | Reserved for Saturn Labs project image |
| `public/images/shyam-bazaar.jpg` | Reserved for Shyam Bazaar project image |
| `public/images/college-stall.jpg` | Reserved for college stall project image |
| `public/images/personal-01.jpg` | Reserved for personal photography |

The first three assets are currently wired into the Next.js version. The remaining named image files are placeholders reserved for a future visual expansion of the project pages.

For the static `site/` version, replace the corresponding files in `site/images/` instead.
